# FMCG Instant Food Feasibility Study

Static GitHub Pages feasibility study for a 1,000 sqm Indian FMCG plant producing 250 g dehydrated instant-food packs for ECOWAS.

- Recommended first site search: Dindigul, Tamil Nadu
- Benchmark: Tuticorin port-side
- Export gateway: V.O. Chidambaranar Port, Tuticorin
- Research snapshot: 19 September 2026
- Dual-currency: INR + USD with editable planning FX

This is a planning feasibility study, not a bankable DPR. Replace assumptions with written quotations and pilot data before committing full CAPEX.
